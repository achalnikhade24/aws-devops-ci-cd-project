## 📌 Project Overview
This project demonstrates an automated CI/CD workflow to build and deploy a web application using GitHub, Jenkins, Docker, Docker Hub, AWS EC2, and Nginx.

The main objective is to automate the application deployment process and understand how DevOps tools work together in a real-world environment.

## 🏗️ Project Architecture

**GitHub → Jenkins → Docker → Docker Hub → AWS EC2 → Nginx → Web Application**

## 🛠️ Technologies Used

- **AWS EC2:** Hosts the application on a cloud virtual machine.
- **Git:** Tracks source code changes.
- **GitHub:** Stores the project source code.
- **Jenkins:** Automates the CI/CD pipeline.
- **Docker:** Builds and runs the application container.
- **Docker Hub:** Stores and distributes the Docker image.
- **Nginx:** Serves the web application.
- **Linux:** Provides the server environment.

## ⚙️ How the Project Works

1. **Source Code Management:** The application code is stored in GitHub.
2. **Continuous Integration:** Jenkins monitors the GitHub repository for code changes.
3. **Automated Build:** Jenkins executes the configured pipeline.
4. **Docker Image:** The application is packaged into a Docker image.
5. **Image Registry:** The Docker image is pushed to Docker Hub.
6. **Cloud Deployment:** The image is deployed as a container on AWS EC2.
7. **Web Hosting:** Nginx serves the application, making the website accessible through the configured endpoint.
